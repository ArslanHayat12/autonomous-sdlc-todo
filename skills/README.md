# Skill catalog

The orchestrator currently selects from this starter catalog in its planning prompt. Keep skills short, scoped, and evidence-driven. Suggested files to add as the project grows:

- `repository-analysis/SKILL.md` — map modules, entry points, and dependency boundaries.
- `typescript-clean-code/SKILL.md` — strict types, small functions, explicit errors.
- `react-accessibility/SKILL.md` — semantic controls, keyboard support, accessible names.
- `api-security/SKILL.md` — validation, auth boundaries, rate limits, safe errors.
- `playwright-testing/SKILL.md` — critical user flows and regression coverage.
- `dependency-security/SKILL.md` — lockfile, npm audit, dependency review.
- `docker-build/SKILL.md` — reproducible build, non-root runtime, health checks.
